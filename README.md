# Relative — a 100% procedural Blender animation about Speed

Entry for the RenderJuice Blender Animation & Programmatic Rendering Contest (theme: **Speed**).

A racer accelerates from 20 km/h to light speed through a Doppler-coloured ring tunnel, slams on the brakes, and finds that a snail has already won.
*SPEED = DISTANCE / TIME. The snail just left earlier.*

Every object, material, light, camera move and text change in the film is generated by `speed.py`. Nothing is modelled or keyframed by hand.

```bash
blender -b -noaudio -P speed.py -- test 40 160 270   # preview frames
blender -b -noaudio -P speed.py -- all               # render frames/0001..0288.png
ffmpeg -framerate 24 -i frames/%04d.png -i sfx.wav -c:v libx264 -pix_fmt yuv420p -shortest relative_speed.mp4
```

## How it works
- **Motion:** a single function `racer_y(frame)` drives the movement. It uses a 0.15t + 0.85t⁴ curve to accelerate and a cubic ease-out to brake. Its derivative controls the trail length, the vibration, the camera shake and the lens (32 mm → 14 mm).
- **Speed readout:** the speed is mapped onto a log scale that ends at 1,079,252,848 km/h. The script rewrites the text before each frame is rendered.
- **Tunnel:** there are 260 ring instances and 700 dust streaks. Each ring gets a hue from its depth in the tunnel, read through Object Info → Color.
- **Snail:** it is built from primitives, with a parametric spiral curve on the shell. It wins the race at 0.25 units per 4 seconds.
- **Sound:** `sfx.py` synthesises it with numpy (engine sweep, wind, brake screech, boing, tuba).

Rendered with Cycles (CPU, 20 samples plus denoising, motion blur), Blender 5.2.

AI disclosure: an AI coding assistant helped write the scripts. No AI-generated images, video, audio or 3D assets were used.
